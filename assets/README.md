# Documentation assets

- `framework.png`: scope-accurate EMS-Splat pipeline schematic.
- `joint_optimizer.png`: detailed objective and cross-view update schematic.
- `h36m_robustness.png/.svg`: plot generated from
  `results/h36m_corrected_summary.csv` by `tools/plot_readme_results.py`.
- `qualitative_skeletons.png`: skeleton-only comparison containing no source
  RGB frames.

The repository deliberately excludes qualitative panels that contain
Human3.6M or CMU Panoptic RGB images. These files are documentation figures,
not a substitute for the licensed base datasets or their annotations.
